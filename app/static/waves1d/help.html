Розмір моделі

W  - ширина модельного простору (100 < W < 10000)
H  - висота модельного простору (100 < H < 10000)
ma - ширина полів (0 <= ma < W/2)

Після змінення параметрів натисніть Enter, щоб зміни почали діяти.
Зміна розмірів створює новий пустий модельний простір

Параметри моделі

k    - жорсткість середовища (0 < k < 1)
loss - втрати енергії у вузлі (0 < loss < 1)

Після змінення параметрів натисніть Enter, щоб зміни почали діяти.
Якщо змін не було, натискання Enter просто заспокоє хвилі.

Режими створення сцен

Inf - виводить дані про обраний об'єкт. Об'єкт обирається мишею.
Sto - будує лінійні перешкоди
Osc - будує точкові і лінійні осцилятори
Mon - будує точкові і лінійні однократні-осцилятори
Rec - будує точкові і лінійні приймачі
Del - видаляє об'єкти мишею. 
В будь-якому режимі права кнопка миші також видаляє об'єкт.

Параметри майбутнього осцилятора

amp - амплітуда
q   - хвильове число = 2π/λ - частина фази коливання, яка припадає на одиницю довжини. 
vx  - швидкість горизонтального руху (1/20 < vx < 1/2)

Параметри майбутнього приймача

loss - коеффіцієнт поглинання  (0 < loss < 1)

Керування переглядом

Кнопка Run   - зупиняє або продовжує плин часу
Клавіша s    - один крок у часі
Слайдер Amp  - змінює масштаб відображення зміщень вузлів.
Слайдер Velo - змінює масштаб відображення швидкості руху вузлів.

Збереження і відтворення сцен

Кнопка ⬇ - зберігає поточну сцену в рядку у форматі JSON. Рядок з'являєтся в області під модельним простіром.
Кнопка ⬆ - відтворює поточну сцену з рядку, який знаходиться в області під модельним простіром.
